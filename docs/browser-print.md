# 兩條列印路徑 — 本機 agent vs. 瀏覽器直印

本系統有 **兩條互不干擾** 的列印路徑,現場可以都試、挑對位比較準的那條。

| | A. 本機 agent(既有) | B. 瀏覽器直印(#K) |
|---|---|---|
| 入口 | 開單頁的 **「🖨 列印」** 按鈕 | 開單頁的 **「⧉ 在新分頁開啟列印預覽」** → `/print-preview` 的列印按鈕 |
| 流程 | 預覽 DOM → PNG → `POST http://localhost:9100/print-image` → agent 轉 ESC/P 圖形 → 印表機 | `/print-preview` 以實體尺寸渲染 → `window.print()` → 系統列印對話框 → 印表機驅動 |
| 需要本機 agent? | **需要**(`print-agent/`,監聽 `:9100`) | **不需要** |
| LQ-310 佇列/驅動 | **Generic / Text Only**(raw,直送 bytes) | **原廠 EPSON LQ-310 驅動**(圖形) |
| 存檔 | 會存檔 + 記錄列印(Supabase) | **不存檔**(純列印) |
| 列印對話框 | 不會跳(agent 直接送印) | **一定會跳**(瀏覽器無法靜默列印) |

> 建議在工廠電腦上把 **兩個印表機佇列都建起來**(同一台 LQ-310:一個 Generic/Text Only、一個原廠 EPSON 驅動),
> 就能現場比較哪條路徑對位、字體、速度比較合用。兩條路徑共用同一份預覽版型與 X/Y 微調概念。

---

## A. 本機 agent 路徑(不變)

見 `print-agent/` 與 `docs/deploy.md` 第 5 節。重點:

- 佇列必須是 **Generic / Text Only**(raw)。用原廠驅動會把 ESC/P bytes 當成文字內容再包一層,印出亂碼。
- 網站可以是 HTTPS(Vercel),Chrome/Edge 把 `http://localhost` 視為安全來源,允許這條 fetch。

## B. 瀏覽器直印路徑(`/print-preview`)

1. 在開單頁填好單,按 **「⧉ 在新分頁開啟列印預覽」**。
   - 目前表單(含未存檔的)會寫進 `localStorage` 的 `do-print-preview`,新分頁再讀回來。
2. 新分頁以 **中一刀實體尺寸 215.9 × 139.7 mm(8.5" × 5.5",橫式)** 呈現送貨單。
   - 螢幕上的**虛線**是紙張邊界 / 安全邊界 / 中線輔助線,**列印時不會印出**。
   - 工具列可即時調 X/Y 微調:`X` 單位 1/60 吋、`Y` 單位 1/180 吋(與 ESC/P 的 `ESC $` / `ESC 3` 一致),
     換算成實體位移 `mm = 單位值 / (60 或 180) × 25.4`,直接以 mm 平移整張單 —— 看到的位移就是印出來的位移。
3. 按 **「🖨 用瀏覽器列印」** → 跳出系統列印對話框。

### 列印對話框務必這樣設(否則對位會跑掉)

- **印表機**:選 **EPSON LQ-310(原廠驅動)**,**不要**選 Generic / Text Only。
- **紙張大小**:`215.9 × 139.7 mm`(若清單沒有,在驅動裡新增自訂紙張;頁面已宣告
  `@page { size: 215.9mm 139.7mm; margin: 0 }`,多數瀏覽器會自動帶入)。
- **邊界(Margins)**:`無 / None`。
- **縮放(Scale)**:`100%`,關閉「符合頁面寬度 / Fit to page」。
- **頁首及頁尾(Headers and footers)**:關閉。
- **背景圖形(Background graphics)**:開啟(才會印出表格底色/框線)。

### 已知限制

- 瀏覽器**無法靜默列印**,一定會跳系統對話框(這是瀏覽器安全限制,不是 bug)。
- 若印出第二張空白頁:通常是邊界沒設成 `無/None`,或紙張大小不是 215.9 × 139.7 mm。
- 針式印表機用**圖形模式**列印較慢、也比較耗色帶;追求速度仍建議走 agent 路徑。
- 新分頁是靠 `localStorage` 交握,所以必須**用同一個瀏覽器設定檔**開啟(無痕模式另開分頁可,但跨瀏覽器不行)。
