## 4. 工期

- 開發總人天:**3.75 人天**(純模組開發)。
- 加上 QA、整合驗收與客戶往返後,實際交付日曆工期預估 **約 1.5–2 週**(單人、非全時投入的合理假設)。
- 里程碑:
  1. M1–M2 資料庫與存查(第 1 週)
  2. M3–M4 品名匯入與 autocomplete(第 1–2 週)
  3. M5 部署上線 + 列印實測 + 驗收(第 2 週)

## 6. 估算依據與自我檢查

- **人天基準**:依 `estimation-guide.md`,中複雜度單模組基準 4–8 人天為「全新開發」值;本專案**已有 MVP 基礎**(表單、列印管線、資料模型皆完成),各模組屬「在既有基礎上擴充」,故取遠低於基準的點估值。此為壓低至 30k 級距的關鍵依據。
- **費率**:NT$6,000/天(使用者指定,偏友情/中小案價)。
- **緩衝**:15% 集中反映列印連線的實測不確定性,已在附加項透明列出。
- **是否漏估**:環境/部署(M5)、匯入(M3)、測試(QA 附加項)均已納入。
- **費率待確認?** 否,已由使用者指定。
